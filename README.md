# MediMate 💊

MediMate is a medicine reminder and tracking web application built using Python and Flask. It helps users organise their medicines, track scheduled doses, and monitor their daily medication records.

## Features
- Add, edit, and delete medicines
- Schedule medicine reminders by time
- Track taken, missed, pending, and overdue doses
- View medication statistics and adherence
- Caregiver dashboard
- Medication history
- Rule-based medicine information assistant

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## Installation and Setup

1. Clone this repository.
2. Open the project folder in the terminal.
3. Create and activate a virtual environment.
4. Install the dependencies:

   ```bash
   pip install -r requirements.txt
   ```

5. Run the application:

   ```bash
   python app.py
   ```

6. Open `http://127.0.0.1:5000` in your browser.
